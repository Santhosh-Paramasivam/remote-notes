# Domain Names

- A string of nested qualifiers that help identify resources on the internet as per the **DNS Protocol**

- The rightmost label is the top-level domains (TLDs), typically 
  - .gov
  - .ca
  - .in 
  - .info

- Then there are second-level and third-level domains. The more leftmost, the more specific.

- A **Hostname** is a domain name that is linked to at least one IP address and therefore identifies hosts

- A **Fully Qualified Domain Name (FQDN)** is a domain name with no ambiguity, and typically ends with a trailing "." (period) to indicate the empty **DNS Root Zone** which is above the top-level domain

- Domain names are case-insensitive
