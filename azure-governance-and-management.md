# Azure Governance and Management

## Cost Management 

- Azure Pricing Tool

### Azure Pricing Tool 

- For gauging the cost of a particular configuration and amount of intrastructure

### Microsoft Cost Management Tool 

- Helps identify costs for resources presently utilized, helps set alerts and budgets

### Azure Consumption API 

- Allows enterprise agreements clients to access cost information programmatically through a REST API?

### Resource tags

- [microsoft-learn-resource-tags](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/7-describe-purpose-of-tags)

- Used to store metadata about resources for security, compliance, resource organization and also cost management

- Any number of key-value pair options such as, team, environment, sensitivity, criticality, and so on

### Cost Optimization Options

- Reservations
- Azure Savings Plan for Compute
- Spot Pricing
